# Jatibarang Helmet — AI Business Management System
Prototipe dashboard web responsif.

## Isi
- Dashboard ringkasan (angka contoh)
- Katalog produk dengan input sederhana
- Ringkasan stok
- Tampilan awal AI Business, AI Marketing, AI Research
- Placeholder pesanan dan laporan

## Cara mencoba
Buka `index.html` dengan browser.

## Catatan
Ini belum merupakan sistem operasional. Belum ada database permanen, autentikasi, integrasi NUSA Kasir, WhatsApp, atau koneksi model AI. Data produk yang dimasukkan hanya tersimpan sementara selama halaman terbuka. Angka omzet/laba adalah ilustrasi, bukan transaksi aktual.

## Tahap selanjutnya
Database dan login; impor katalog CSV/Excel; verifikasi ekspor NUSA; laporan aktual; integrasi AI; alur pesanan WhatsApp.
